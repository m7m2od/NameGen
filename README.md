# WaveNet Character-Level Language Model 🌊

A PyTorch implementation of a WaveNet-inspired character-level language model for name generation. This project demonstrates deep learning fundamentals through a clean, educational implementation that generates realistic names by learning character-level patterns.


## ✨ Features

- **Custom Neural Network Implementation**: Built from scratch with custom layers (Linear, BatchNorm, Embedding, etc.)
- **WaveNet-Inspired Architecture**: Hierarchical processing with consecutive flattening
- **Character-Level Generation**: Learns to generate names one character at a time
- **Comprehensive Training Pipeline**: Complete training, validation, and evaluation framework
- **Modular Design**: Clean, educational code structure perfect for learning
- **Interactive Examples**: Easy-to-use scripts for quick experimentation
